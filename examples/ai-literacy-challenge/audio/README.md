# Audio Files for A.I. Literacy Challenge

This folder stores pre-recorded narration used by `ai-literacy-game.html`.

## Folder structure

- `level1/` → audio for Nível 1 questions
- `level2/` → audio for Nível 2 questions
- `level3/` → audio for Nível 3 questions

## How to generate audio (Google AI Studio)

1. Open: https://aistudio.google.com/generate-speech
2. Paste the full question narration text (concept, script, and options).
3. Choose a Portuguese voice (pt-BR preferred).
4. Configure voice settings for educational content:
   - Speaking style: clear and calm
   - Speed/rate: medium (avoid very fast output)
   - Stability/expressiveness: balanced for comprehension
5. Export/download the result as **MP3**.
6. Save the file in the correct level folder using the naming convention below.

## Naming convention

- One MP3 per question.
- Use the question concept in lowercase as the filename.
- Examples:
  - `llm.mp3`
  - `token.mp3`
  - `prompt-edu.mp3`

## Audio format recommendations

- Format: **MP3**
- Recommended bitrate: **128 kbps**
